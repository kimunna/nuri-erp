## 1. 현행 업무와 문제

### 1.1 부서별 문제

| 부서 | 가장 큰 문제 | 그 결과 |
|---|---|---|
| 영업팀 | 출하 가능 수량을 바로 알 수 없음 | 고객 답변이 반나절~하루 늦음, 납기 지연 월 3건 |
| 구매자재팀 | 재고 엑셀이 여러 버전, 안전재고 기준이 머릿속에만 있음 | 원자재 바닥을 생산 중단 뒤에 앎 (올해 2회) |
| 생산팀 | 작업지시서가 종이 | 급한 주문의 순서 변경이 현장에 늦게 전달됨 |
| 품질팀 | 불량 기록이 품질팀 엑셀에만 있음 | 출하 직전에 전화로 확인 |
| 경영지원팀 | 월말에 부서별 엑셀을 손으로 합침, 결재가 종이 | 마감 3일 소요, 미수금 즉시 확인 불가, 결재 지연 |
| 요약 | **같은 정보가 부서마다 따로 있고, 확인은 전화로** | 답변 지연 · 재고 불일치 · 마감 지연 |

### 1.2 현행 업무 흐름

수주 → (전화로) 재고 확인 → (전화로) 생산 요청 → 종이 작업지시 → 출하 → 월말에 엑셀 합쳐 매출 집계 → 수금 확인.
그림은 `docs/현행업무흐름.md` 참고.

## 2. 사용자와 역할

| 역할 | 누구 | 주로 하는 일 | 주로 보는 화면 |
|---|---|---|---|
| 대표 | 대표 1명 | 최종 결재, 경영 현황 확인 | 경영 대시보드, 결재함 |
| 부서장 | 팀장 5명 | 부서 업무 관리, 1차 결재 | 자기 부서 모듈, 결재함 |
| 직원 | 사무직 8명 | 수주 · 발주 · 입고 · 실적 입력 | 자기 업무 모듈 |
| 현장 | 생산직 (조회만) | 오늘의 작업지시 확인 | 작업지시 목록 (휴대폰) |
| 요약 | 4개 역할 | 입력하는 사람과 보는 사람이 다름 | 역할마다 다른 메뉴 |

## 3. 요구사항 목록

### 3.1 필수 (v1.0에 반드시 포함)

| ID | 부서 | 요구사항 | 확인 방법 (수용 기준) | 출처 |
|---|---|---|---|---|
| REQ-001 | 공통 | 품목(완제품 · 원자재)과 거래처를 등록 · 수정 · 조회한다 | 품목 38종, 거래처 25곳이 목록에 보인다 | 회사소개 |
| REQ-002 | 영업 | 고객 · 품목 · 수량 · 납기로 수주를 등록한다 | 수주 1건 등록 후 목록에 납기순으로 보인다 | 영업팀장 인터뷰 |
| REQ-003 | 영업 | 품목별 **출하 가능 수량**을 바로 본다 | 품목 화면에서 클릭 2번 안에 수량이 보인다 | 영업팀장 인터뷰 |
| REQ-004 | 재고 | 입고 · 출고하면 재고 수량이 자동으로 바뀐다 | 출하 100개 처리 후 재고가 정확히 100 줄어든다 | 구매자재팀장 인터뷰 |
| REQ-005 | 재고 | 재고가 안전재고 아래면 경고한다 | 기준 아래 품목에 대시보드 경고가 표시된다 | 구매자재팀장 인터뷰 |
| REQ-006 | 구매 | 원자재 발주를 등록하고, 입고 시 발주와 연결한다 | 발주 1건 → 입고 처리 → 발주 상태가 "입고 완료" | 구매자재팀장 인터뷰 |
| REQ-007 | 생산 | 완제품별 BOM(재료 목록)을 관리한다 | 완제품 1개 선택 시 필요 원자재와 수량이 보인다 | 생산 인터뷰 메모 |
| REQ-008 | 생산 | 작업지시를 납기 급한 순서로 보여준다 | 작업지시 목록이 납기순으로 정렬된다 | 생산 인터뷰 메모 |
| REQ-009 | 생산 | 생산 실적을 입력하면 완제품 재고가 늘고 원자재가 BOM만큼 줄어든다 | 실적 10개 입력 → 완제품 +10, 원자재 BOM×10 감소 | 생산 인터뷰 메모 |
| REQ-010 | 회계 | 출하하면 매출이, 입고하면 매입이 자동 기록된다 | 출하 1건 후 매출 목록에 같은 금액이 생긴다 | 경영지원 인터뷰 메모 |
| REQ-011 | 회계 | 미수금과 월 매출 · 매입 합계를 언제든 본다 | 버튼 한 번으로 월 합계가 나오고, 예시 값으로 검산된다 | 경영지원 인터뷰 메모 |
| REQ-012 | 공통 | 역할마다 보이는 메뉴가 다르다 | 역할 4개로 바꿔 보면 메뉴가 각각 다르다 | 사용자 분석 |
| REQ-013 | 공통 | 구매 · 지출은 기안 → 부서장 → 대표 순서로 결재한다 | 결재 1건이 3단계를 거쳐 "승인"이 된다 | 경영지원 인터뷰 메모 |
| REQ-014 | 공통 | 대표가 매출 · 재고 경고 · 미수금을 한 화면에서 본다 | 대시보드 한 화면에 세 가지가 모두 보인다 | 대표 인터뷰 메모 |
| REQ-015 | 공통 | 휴대폰에서도 화면이 깨지지 않는다 | 가로 375px 화면에서 작업지시 목록이 읽힌다 | 대표 · 생산 메모 |
| 요약 | 6개 부서 | **필수 15개** | 모두 Day07 인수 테스트의 체크 항목이 됨 | |
