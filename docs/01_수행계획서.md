> 상태: **확정** — 범위와 성공 기준을 요구사항 정의서에 맞춰 정했습니다.

## 1. 목적

(주)누리정밀은 부서마다 엑셀 파일을 따로 씁니다.
공유 폴더에 30여 개가 있습니다.
부서 사이 확인은 전화와 메신저로 하고, 결재는 종이로 합니다.

그래서 이런 일이 생깁니다.

- 같은 정보가 부서마다 다르게 적혀 있습니다.
- 다른 부서 정보를 보려면 전화를 해야 합니다.
- 대표가 자리에 없으면 결재가 멈춥니다.

이 프로젝트의 목적은 하나입니다.

> **엑셀 30개를 하나의 시스템으로 합쳐, 누가 입력하면 다른 부서도 바로 보이게 한다.**
> — 대표 요청 (가상 인물)

| 구분 | 지금 | 바뀐 뒤 |
|---|---|---|
| 데이터 | 부서별 엑셀 30여 개 | 시스템 하나 |
| 부서 간 확인 | 전화·메신저 | 화면에서 바로 조회 |
| 결재 | 종이 결재판 | 시스템 결재 (출장 중에도 가능) |
| 요약 | 따로 입력, 전화로 확인 | **한 번 입력, 모두가 확인** |

## 2. 범위 (모듈 수준)

> 요구사항 정의서(`docs/02_요구사항정의서.md`)의 필수 16개를 기준으로 정했습니다.
> 필수 범위는 6개 모듈입니다.

### 2.1 포함할 모듈 (필수)

| 모듈 | 담당 부서 | 다루는 업무 | 대체할 엑셀 | 요구사항 |
|---|---|---|---|---|
| 기준정보 | 공통 | 품목(38종), 거래처(고객 15곳·공급사 10곳), 사용자·역할 | 각 부서 엑셀에 흩어진 목록 | REQ-001, REQ-002 |
| 영업 | 영업팀 · 품질팀 | 수주, 납기, 출하 가능 수량, 출하 검사 통과 확인, 출하 | `수주대장_2026.xlsx` | REQ-003, REQ-004, REQ-005, REQ-016 |
| 구매·재고 | 구매자재팀 | 발주, 입고, 재고 현황, 안전재고 경고 | `발주대장.xlsx`, `재고현황_최종_수정3.xlsx` | REQ-006, REQ-007, REQ-008 |
| 생산 | 생산팀 | BOM, 작업지시(납기순), 생산 실적 | 종이 작업지시서, `생산일보.xlsx` | REQ-009, REQ-010, REQ-011 |
| 회계 | 경영지원팀 · 대표 | 매출·매입, 미수금, 월 합계, 대표 현황 화면 | `매출매입_월별.xlsx`, `미수금현황.xlsx`, 월간 경영 회의 자료 | REQ-012, REQ-013, REQ-014 |
| 결재 | 공통 | 구매·지출 기안 → 팀장 → 대표 결재 | 종이 결재판 | REQ-015 |
| 요약 | **6개 모듈** | 수주 → 생산·구매 → 출하 → 매출 → 수금 흐름 전체 | 엑셀 30여 개 + 종이 | **필수 16개** |

> 대표 현황 화면은 따로 모듈을 두지 않고 회계 모듈의 조회 화면으로 만듭니다.
> 출하 검사 확인은 품질 모듈 없이 영업의 출하 화면에서 "검사 통과" 표시로 처리합니다.

### 2.2 시간이 남으면 할 것 (확장)

| 항목 | 담당 부서 | 요구사항 | 이유 |
|---|---|---|---|
| 고객사별 단가 자동 적용 | 영업팀 | REQ-017 | 단가 변경 주기가 아직 확인되지 않음 |
| 품질 모듈 (검사 결과 기록, 불량 조회) | 품질팀 | REQ-018, REQ-019 | 품질팀장이 우선순위 낮다고 함 |
| 월말 재고 실사 조정 | 구매자재팀 | REQ-020 | 재고 일원화(REQ-008)가 먼저 |
| 인사·근태 (직원 명부, 근태 기록) | 경영지원팀 | REQ-021, REQ-022 | 기존 급여 프로그램이 있음 |
| 요약 | 4개 항목 | **확장 6개** | 필수가 모두 끝난 뒤 진행 |

## 6. 성공 기준

> 요구사항 정의서의 필수 16개를 기준으로 정했습니다.

| 번호 | 기준 | 확인 방법 | 관련 요구사항 |
|---|---|---|---|
| S1 | 필수 요구사항을 모두 통과한다 | 인수 테스트에서 필수 16개 전부 "통과" | REQ-001 ~ REQ-016 |
| S2 | 한 부서가 입력하면 다른 부서가 바로 본다 | 수주 → 생산 → 검사 통과 → 출하 → 매출이 전화 없이 화면에서 이어진다 | REQ-003, REQ-011, REQ-016, REQ-005, REQ-012 |
| S3 | 영업이 출하 가능 수량을 바로 답한다 | 품목을 고르면 재고 + 생산 중 수량이 한 화면에 보인다 | REQ-004 |
| S4 | 재고 숫자가 하나로 맞는다 | 입고·생산·출하 후 재고가 계산값과 같고, 안전재고 아래면 경고가 뜬다 | REQ-006, REQ-007, REQ-008, REQ-011 |
| S5 | 결재가 종이 없이 끝난다 | 결재 1건이 기안부터 대표 승인까지 시스템에서 끝난다 | REQ-015 |
| S6 | 대표가 휴대폰 한 화면에서 현황을 본다 | 가로 375px 화면에 매출·재고 경고·미수금이 함께 보인다 | REQ-014 |
| S7 | 8일 안에 끝난다 | Day08 결과 발표 완료 | — |
| 요약 | 7개 | S1~S6은 Day07 인수 테스트, S7은 Day08에 확인 | |
