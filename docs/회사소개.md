## 4. 지금 일하는 방식

- 부서마다 **엑셀 파일을 따로** 씁니다. 공유 폴더에 30여 개가 있습니다.
  - 영업팀: `수주대장_2026.xlsx`, `고객사별_단가표.xlsx`
  - 구매자재팀: `발주대장.xlsx`, `재고현황_최종_수정3.xlsx`
  - 생산팀: 종이 작업지시서 + `생산일보.xlsx`
  - 품질팀: `불량기록.xlsx`
  - 경영지원팀: `매출매입_월별.xlsx`, `미수금현황.xlsx`
- 부서 사이의 연락은 **전화와 메신저**로 합니다.
- 결재는 **종이 결재판**으로 합니다. 대표가 출장 중이면 결재가 멈춥니다.
