## 1. 목적

(주)누리정밀은 부서마다 엑셀 파일을 따로 씁니다.
공유 폴더에 30여 개가 있습니다.
부서 사이 확인은 전화와 메신저로 하고, 결재는 종이로 합니다.

그래서 이런 일이 생깁니다.

- 같은 정보가 부서마다 다르게 적혀 있습니다.
- 다른 부서 정보를 보려면 전화를 해야 합니다.
- 대표가 자리에 없으면 결재가 멈춥니다.

이 프로젝트의 목적은 하나입니다.

> **엑셀 30개를 하나의 시스템으로 합쳐, 누가 입력하면 다른 부서도 바로 보이게 한다.**
> — 대표 요청 (가상 인물)

| 구분 | 지금 | 바뀐 뒤 |
|---|---|---|
| 데이터 | 부서별 엑셀 30여 개 | 시스템 하나 |
| 부서 간 확인 | 전화·메신저 | 화면에서 바로 조회 |
| 결재 | 종이 결재판 | 시스템 결재 (출장 중에도 가능) |
| 요약 | 따로 입력, 전화로 확인 | **한 번 입력, 모두가 확인** |

## 2. 범위 (모듈 수준) `분석 후 확정`

> 아래는 회사소개 자료만 보고 잡은 1차 범위입니다.
> 부서 인터뷰와 요구사항 분석이 끝나면 확정합니다.

### 2.1 포함할 모듈

| 모듈 | 담당 부서 | 다루는 업무 | 대체할 엑셀 |
|---|---|---|---|
| 기준정보 | 공통 | 품목(38종), 거래처(고객 15곳·공급사 10곳), BOM, 사용자 | 각 부서 엑셀에 흩어진 목록 |
| 영업 | 영업팀 | 수주, 납기, 출하 요청 | `수주대장_2026.xlsx`, `고객사별_단가표.xlsx` |
| 구매·재고 | 구매자재팀 | 발주, 입고, 재고 현황 | `발주대장.xlsx`, `재고현황_최종_수정3.xlsx` |
| 생산 | 생산팀 | 작업지시, 생산 실적 | 종이 작업지시서, `생산일보.xlsx` |
| 품질 | 품질팀 | 입고·출하 검사, 불량 기록 | `불량기록.xlsx` |
| 회계 | 경영지원팀 | 매출·매입, 미수금, 월말 집계 | `매출매입_월별.xlsx`, `미수금현황.xlsx` |
| 결재 | 공통 | 기안 → 부서장 → 대표 결재 | 종이 결재판 |
| 대시보드 | 대표 | 매출·재고·미수금 한눈에 보기 | 월간 경영 회의 자료 |
| 요약 | **8개 모듈** | 6개 부서 업무 전체 | 엑셀 30여 개 + 종이 |

### 2.2 이번에 하지 않을 것 (예상)

## 6. 성공 기준 `분석 후 확정`

> 아래 기준은 가안입니다.
> 요구사항 정의서가 확정되면 숫자와 항목을 다시 맞춥니다.

| 번호 | 기준 | 확인 방법 |
|---|---|---|
| S1 | 필수 요구사항을 모두 통과한다 | 인수 테스트에서 필수 항목 전부 "통과" |
| S2 | 한 부서가 입력하면 다른 부서가 바로 본다 | 수주 → 생산 → 출하 → 매출이 전화 없이 화면에서 이어진다 |
| S3 | 재고 숫자가 하나로 맞는다 | 입고·생산·출하 후 재고가 계산값과 같다 |
| S4 | 결재가 종이 없이 끝난다 | 결재 1건이 기안부터 대표 승인까지 시스템에서 끝난다 |
| S5 | 대표가 한 화면에서 현황을 본다 | 대시보드에 매출·재고 경고·미수금이 함께 보인다 |
| S6 | 8일 안에 끝난다 | Day08 결과 발표 완료 |
| 요약 | 6개 | S1~S5는 Day07 인수 테스트, S6은 Day08에 확인 |
