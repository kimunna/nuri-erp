# 누리정밀 통합 ERP (가상 회사 실습용)

## 회사 소개

자동차•가전용 정밀 금속 부품 제조, 직원 40명

## 이 저장소의 목적

8일 동안 통합 업무 시스템을 만든다.

## 일정표

| 일차 | 주제 | 주요 작업 |
|------|------|-----------|
| 1일차 | 준비와 설계 | 업무 흐름 정리, 데이터 구조 설계, 개발 환경 준비 |
| 2일차 | 기준정보 | 품목(부품·원자재), 거래처, 사원 관리 |
| 3일차 | 영업 | 수주 등록, 출하, 납기 관리 |
| 4일차 | 구매·재고 | 발주, 입고, 재고 현황 |
| 5일차 | 생산 | 작업지시, 생산 실적, 설비 관리 |
| 6일차 | 품질 | 입고·공정·출하 검사, 불량 관리 |
| 7일차 | 인사·회계 | 근태 관리, 매출·매입 집계 |
| 8일차 | 통합과 마무리 | 대시보드, 통합 테스트, 결과 발표 |

---

> 이 저장소에 나오는 회사와 인물은 가상이며, 실제 회사•인물과 관계없음.
