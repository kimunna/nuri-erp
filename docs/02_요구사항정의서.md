## 1. 현행 업무와 문제

### 1.1 부서별 문제

| 부서 | 가장 큰 문제 | 그 결과 |
|---|---|---|
| 영업팀 | 출하 가능 수량을 바로 알 수 없음 (재고·생산 수량을 전화로 확인) | 고객 답변에 반나절~하루, 지난달 납기 지연 3건 (1건 위약금) |
| 구매자재팀 | 재고 엑셀이 3개 버전, 안전재고 기준이 머릿속에만 있음 | 원자재 바닥을 라인이 멈춘 뒤에 앎 (올해 2회), 실사 차이 5~10% |
| 생산팀 | 작업지시서가 종이, 실적은 하루 끝에 몰아서 입력 | 급한 주문의 순서 변경이 현장에 늦게 전달됨 |
| 품질팀 | 불량·검사 기록이 품질팀 엑셀에만 있음 | 출하 직전에 전화로 검사 통과를 확인 |
| 경영지원팀 | 월말에 부서별 엑셀을 손으로 합침, 결재가 종이 | 마감 3일 소요, 미수금 즉시 확인 불가, 대표 출장 중 결재 지연 |
| 대표 | 부서별 엑셀을 월 1회 받아 봄 | 숫자가 서로 안 맞을 때가 많음 |
| 요약 | **같은 정보가 부서마다 따로 있고, 확인은 전화로** | 답변 지연 · 재고 불일치 · 마감 지연 |

### 1.2 현행 업무 흐름

수주 → (전화로) 재고·생산 수량 확인 → (전화로) 생산 요청 → 종이 작업지시 → (전화로) 출하 검사 확인 → 출하 → 월말에 엑셀 합쳐 매출 집계 → 수금 확인.
그림은 `docs/현행업무흐름.md` 참고.

## 2. 사용자와 역할

| 역할 | 누구 | 주로 하는 일 | 주로 보는 화면 |
|---|---|---|---|
| 대표 | 대표 1명 | 최종 결재, 경영 현황 확인 | 대표 현황 화면, 결재함 (휴대폰 포함) |
| 부서장 | 팀장 5명 | 부서 업무 관리, 1차 결재 | 자기 부서 모듈, 결재함 |
| 직원 | 사무직 8명 | 수주 · 출하 · 발주 · 입고 · 실적 입력, 출하 검사 통과 표시 | 자기 업무 모듈 |
| 현장 | 생산직 (조회만) | 오늘의 작업지시 확인 | 작업지시 목록 (휴대폰) |
| 요약 | 4개 역할 | 입력하는 사람과 보는 사람이 다름 | 역할마다 다른 메뉴 |

## 3. 요구사항 목록

필수 요구사항은 **6개 모듈** 안에서 정했습니다.
기준정보 · 영업 · 구매·재고 · 생산 · 회계 · 결재입니다.

- 대표 현황 화면(REQ-014)은 회계 모듈의 조회 화면으로 넣었습니다.
- 출하 전 검사 확인(REQ-016)은 품질 모듈 없이 영업의 출하 화면에서 처리합니다.

### 3.1 필수 (v1.0에 반드시 포함)

| ID | 부서 | 요구사항 | 우선순위 | 확인 방법 (수용 기준) | 출처 |
|---|---|---|---|---|---|
| REQ-001 | 공통 | 품목과 거래처를 등록·수정·조회한다. | 필수 | 목록에 품목 38종, 거래처 25곳이 보인다 | 회사소개 |
| REQ-002 | 공통 | 역할(대표·부서장·직원·현장)마다 보이는 메뉴가 다르다. | 필수 | 역할 4개로 로그인하면 메뉴가 각각 다르다 | 회사소개(조직), 컨설턴트 메모 |
| REQ-003 | 영업 | 고객·품목·수량·납기로 수주를 등록하면 생산팀도 바로 본다. | 필수 | 영업이 수주 1건을 등록하면 생산 화면에 납기와 함께 바로 보인다 | 영업팀 메모, 영업팀장 역할극 |
| REQ-004 | 영업 | 품목별 출하 가능 수량(재고 + 생산 중)을 한 화면에서 본다. | 필수 | 화면 값이 재고 + 생산 중 수량 계산값과 같다 | 영업팀 메모, 영업팀장 역할극 |
| REQ-005 | 영업 | 출하를 등록하면 완제품 재고가 줄어든다. | 필수 | 100개 출하하면 재고가 정확히 100 줄어든다 | 컨설턴트 메모(핵심 흐름) |
| REQ-006 | 구매자재 | 발주를 등록하고, 입고를 발주와 연결하면 재고가 는다. | 필수 | 발주 → 입고 처리 → 상태 "입고 완료", 재고 증가 | 구매자재팀 메모 |
| REQ-007 | 구매자재 | 재고가 안전재고 아래로 내려가면 경고한다. | 필수 | 기준 아래로 출고하면 경고가 뜬다 | 구매자재팀 메모 |
| REQ-008 | 구매자재 | 재고 숫자는 시스템 한 곳에서만 관리한다. | 필수 | 입고·생산·출하 후 재고가 계산값과 같다 | 구매자재팀 메모(엑셀 3개 버전) |
| REQ-009 | 생산 | 완제품별 BOM(재료 목록)을 관리한다. | 필수 | 완제품을 고르면 필요한 원자재와 수량이 보인다 | 생산팀 메모 |
| REQ-010 | 생산 | 작업지시를 납기 급한 순서로 보여 준다(휴대폰 포함). | 필수 | 가로 375px 화면에서 납기순 목록이 읽힌다 | 생산팀 메모 |
| REQ-011 | 생산 | 실적을 입력하면 완제품은 늘고 원자재는 BOM만큼 준다. | 필수 | 10개 입력 → 완제품 +10, 원자재 BOM×10 감소 | 생산팀 메모 |
| REQ-012 | 경영지원 | 출하하면 매출·미수금이, 입고하면 매입이 자동 기록된다. | 필수 | 출하 1건 후 매출·미수금에 같은 금액이 생긴다 | 경영지원팀 메모 |
| REQ-013 | 경영지원 | 미수금과 월 매출·매입 합계를 언제든 바로 본다. | 필수 | 버튼 한 번으로 월 합계가 나오고 예시 값으로 검산된다 | 경영지원팀 메모 |
| REQ-014 | 대표 | 매출·재고 경고·미수금을 한 화면에서 휴대폰으로도 본다. | 필수 | 휴대폰 화면 하나에 세 가지가 모두 보인다 | 대표 메모 |
| REQ-015 | 공통 | 구매·지출은 기안 → 팀장 → 대표 순으로 시스템에서 결재한다. | 필수 | 결재 1건이 3단계를 거쳐 "승인"이 된다 | 경영지원팀 메모, 컨설턴트 메모 |
| REQ-016 | 품질·영업 | 품질팀이 "검사 통과"를 표시한 건만 출하할 수 있다. | 필수 | 표시 없이 출하하면 막히고, 표시하면 출하된다 | 품질팀 메모(출하 직전 전화 확인), PM 결정 |
| 요약 | 6개 부서 + 대표 | **필수 16개 (6개 모듈)** | 필수 | 모두 Day07 인수 테스트의 체크 항목이 됨 | |

### 3.2 확장 (시간이 남으면)

| ID | 부서 | 요구사항 | 우선순위 | 확인 방법 (수용 기준) | 출처 |
|---|---|---|---|---|---|
| REQ-017 | 영업 | 수주할 때 고객사별 단가를 자동으로 불러온다. | 확장 | 고객사를 고르면 해당 단가가 채워진다 | 영업팀 메모 |
| REQ-018 | 품질 | 입고·출하 검사 결과를 기록하면 출하 화면에 자동으로 붙는다. | 확장 | 검사 결과 1건 등록 후 출하 화면에 보인다 | 품질팀 메모 |
| REQ-019 | 품질 | 불량 기록을 영업팀도 조회한다. | 확장 | 영업 역할로 불량 목록이 보인다 | 품질팀 메모 |
| REQ-020 | 구매자재 | 월말 실사 결과로 재고 수량을 조정한다. | 확장 | 실사 수량을 입력하면 재고와 차이 기록이 남는다 | 구매자재팀 메모(차이 5~10%) |
| REQ-021 | 경영지원 | 직원 명부를 관리한다. | 확장 | 직원 1명을 등록·수정할 수 있다 | 경영지원팀 메모(기존 급여 프로그램 있음) |
| REQ-022 | 경영지원 | 근태를 기록한다. | 확장 | 직원 1명의 근태 1건이 입력된다 | 경영지원팀 메모(기존 급여 프로그램 있음) |
| 요약 | 4개 부서 | **확장 6개** | 확장 | 필수가 모두 끝난 뒤 남는 시간에 진행 | |
