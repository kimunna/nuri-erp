# 용어사전

제조업 ERP에서 자주 쓰는 용어 10개를 정리했어요.
예시에 나오는 회사와 제품은 모두 가상이에요.

| 용어 | 쉬운 설명 | 누리정밀 예시 |
|------|-----------|---------------|
| 수주 | 고객에게 주문을 받는 것 | 가람모터스에서 브레이크 브래킷 5,000개 주문을 받았다. |
| 발주 | 우리가 공급사에 물건을 주문하는 것 | 브래킷을 만들려고 한빛철강에 냉연강판 2톤을 주문했다. |
| 출하 | 만든 제품을 고객에게 내보내는 것 | 완성된 브래킷 5,000개를 트럭에 실어 가람모터스로 보냈다. |
| 입고 | 주문한 물건이 회사 창고에 들어오는 것 | 한빛철강의 냉연강판 2톤이 도착해 자재 창고에 넣었다. |
| BOM | 제품 하나를 만드는 데 필요한 재료와 수량 목록 | 냉장고 문 힌지 1개 = 강판 0.2kg + 핀 1개 + 와셔 2개. |
| 안전재고 | 갑자기 모자라지 않도록 늘 남겨 두는 최소 수량 | 냉연강판은 항상 500kg 이상 남겨 둔다. |
| 리드타임 | 주문부터 받기까지 걸리는 시간 | 강판은 발주 후 입고까지 7일, 브래킷 생산은 3일이 걸린다. |
| 작업지시 | 현장에 "무엇을 언제 얼마나 만들라"고 내리는 지시 | 프레스 2호기에 내일 오전까지 힌지 2,000개를 만들라고 지시했다. |
| 매출채권 | 물건은 팔았지만 아직 받지 못한 돈 | 가람모터스에 출하한 브래킷 대금 1,500만 원을 다음 달 말에 받는다. |
| 재고실사 | 장부상 재고와 실제 창고 재고를 직접 세어 맞춰 보는 것 | 월말에 창고를 세어 보니 핀이 장부보다 30개 적어 수량을 고쳤다. |
| **요약** | **주문받고(수주) → 재료 사고(발주·입고) → 만들고(BOM·작업지시) → 보내고(출하) → 돈 받는(매출채권) 흐름** | **안전재고·리드타임으로 모자람을 막고, 재고실사로 장부와 실제를 맞춘다.** |
