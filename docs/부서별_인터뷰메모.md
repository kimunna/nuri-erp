# 부서별 인터뷰 메모

> ⚠️ **가상 회사 실습용 자료입니다.** 등장 인물과 숫자는 모두 지어낸 것입니다.
> 시스템 도입 컨설턴트가 부서장들과 15분씩 이야기하고 남긴 메모입니다. 정리되지 않은 상태 그대로입니다.

---

## 영업팀 — 팀장 (가상 인물)

- 고객이 "○○ 브래킷 500개 다음 주까지 되나요?" 하고 물으면 바로 답을 못 함
  - 창고 재고는 구매자재팀 엑셀, 생산 중인 수량은 생산팀 일보 → 둘 다 전화로 확인
  - 답하는 데 평균 반나절~하루
- 수주대장에 납기일을 적지만, 생산팀은 그걸 안 봄 (따로 전화로 알려줌)
- 지난달 납기 지연 3건. 그중 1건은 위약금 발생 (금액 기준은 계약마다 다름)
- 고객사별 단가가 달라서 견적 낼 때 단가표를 매번 찾아봄
- 바라는 것: **"품목별로 지금 출하할 수 있는 수량"이 한 화면에 보였으면**

## 구매자재팀 — 팀장 (가상 인물)

- 재고현황 엑셀 파일이 3개 버전이 돌아다님. 어느 게 최신인지 모를 때가 있음
- 원자재가 바닥난 걸 생산 라인이 멈춘 뒤에 알게 된 적이 올해 2번
- 안전재고 기준은 머릿속에만 있음 (예: 강판은 2주치는 있어야 함)
- 발주서는 워드 양식에 써서 팩스·메일로 보냄. 입고되면 엑셀에 손으로 더함
- 월말에 창고 실사를 하면 엑셀과 실제 수량이 매번 다름 (차이 5~10%)
- 바라는 것: **재고가 안전재고 아래로 내려가면 알려 주는 기능**

## 생산팀 — 생산관리 담당 (가상 인물)

- 작업지시서는 종이. 급한 주문이 들어오면 순서를 바꾸는데, 현장에 전달이 늦음
- 생산 실적(몇 개 만들었는지)은 하루가 끝나고 엑셀 생산일보에 몰아서 입력
- 완제품 하나에 어떤 원자재가 얼마나 드는지(BOM)는 엑셀 한 장에 정리돼 있으나 오래됨
- 바라는 것: **오늘 만들어야 할 것 목록이 급한 순서대로 보였으면**

## 품질팀 — 팀장 (가상 인물)

- 불량 기록은 품질팀 엑셀에만 있음. 영업팀은 모름
- 출하 검사 통과 여부를 출하 직전에 전화로 확인함
- 바라는 것: 출하 전에 검사 결과가 자동으로 붙었으면 (우선순위는 낮다고 함)

## 경영지원팀 — 과장 (가상 인물)

- 월말 마감에 3일 걸림: 영업 매출, 구매 매입, 재고 금액을 각 부서 엑셀에서 모아 합침
- 미수금(아직 못 받은 돈)이 얼마인지 대표가 물으면 바로 답을 못 함
- 결재가 종이라서 대표 출장 중에는 구매 결재가 며칠씩 밀림
- 인사·급여는 별도 급여 프로그램을 쓰고 있어서 이번 시스템에 꼭 넣지 않아도 됨
- 바라는 것: **월말 마감을 하루 안에, 미수금은 언제든 바로**

## 대표 (가상 인물)

- 한 달에 한 번 경영 회의에서 부서별 엑셀을 받아 봄. 숫자가 서로 안 맞을 때가 많음
- 바라는 것: **매출·재고·미수금이 한 화면에** / 휴대폰으로도 보고 싶음
- 예산: 큰돈은 못 씀. 직원들이 직접 만들어 볼 수 있다면 좋겠다

## 컨설턴트 메모 (정리 안 됨)

- 공통 문제: 같은 정보가 부서마다 따로 있음 → 입력은 한 번, 조회는 모두가
- 핵심 흐름: 수주 → 재고 확인 → (부족하면) 생산·구매 → 출하 → 매출 → 수금
- 품질·인사는 급하지 않음
- 결재 흐름(기안 → 팀장 → 대표)은 구매·지출에 꼭 필요
- 확인 필요: 위약금 기준, 안전재고 기준 수치, 고객사별 단가 변경 주기
